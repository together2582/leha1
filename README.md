# 중단시간 분석 도구

올해와 전년의 중단시간을 설비별로 취합하고 비교하는 도구입니다. 기준 문서: `중단시간_분석도구_기획서.md`

## 사용

1. `중단시간_분석도구.html`을 크롬이나 엣지로 엽니다. (설치 필요 없음, 자료는 PC 밖으로 나가지 않음)
2. 올해·전년 엑셀을 올리고 분석 시작
3. 되묻는 분류에 답하고, 확인 목록을 고치거나 제외
4. 결과 엑셀 받기

`samples/`의 엑셀은 테스트용 가짜 데이터입니다.

## 구조

- `src/logic.js` 읽기·분류·계산 규칙
- `src/app.html` 화면
- `build.py` 위 두 파일과 SheetJS를 합쳐 `중단시간_분석도구.html` 1개로 만듦
